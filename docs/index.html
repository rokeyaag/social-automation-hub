Module 4 • Security & Infrastructure

Enterprise Architecture & Token Vault

Engineered with defense-in-depth principles for credential management and API throughput.

Fernet AES-256 Vault

OAuth2 access tokens and Facebook Page long-lived tokens are never stored in plain text. Encrypted at rest using AES-128-CBC + HMAC-SHA256 authentication with secret master key derivation.

FastAPI Async Core

High-concurrency async endpoints for instant response times. Background tasks offload heavy file I/O and HTTP requests without blocking the event loop or user experience.

Multi-Threaded Daemon

APScheduler 3.10 with SQLite persistent job store ensures scheduled posts survive system reboots and fail gracefully with automatic retry exponential backoff policies.
